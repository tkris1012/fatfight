# ぷにっとファイト 🐩☁️

ダイエットをゲーム感覚で続けられるWebアプリ（試作版）。

- 食べたもの → もこもこの脂肪モンスター「モフラ」になって攻めてくる
- 基礎代謝 → 1日かけてじわじわ削る「バリア」
- 運動 → 分身ペット「もちプー」（トイプードル×大福）の攻撃
- 夜をこえて倒しきれたら「脂肪のお城」にダメージ。残ったモフラはお城に住みつく
- **お城のHP ＝ 実際の体脂肪量(kg) × 7,200kcal**。ゲームで勝つことと現実で痩せることが一致する

## 現実との整合性
| 項目 | 計算方法 |
|---|---|
| 基礎代謝 | Mifflin-St Jeor式 |
| 1日の消費 | 基礎代謝 × 活動量（1.2 / 1.375 / 1.55）× 真実の鏡の補正 |
| 運動 | (METs − 1) × 体重 × 時間 × 1.05（基礎代謝との二重計上を除く） |
| 体脂肪率（未入力時） | Deurenberg式で推定 |
| 真実の鏡 | 体重の実測変化から本当の消費カロリーを逆算し、推定を補正（±15%/回） |

## 安全のためのルール
- 記録がない日は「霧の日」（勝ちにも負けにもしない → 記録しないほうが得、を作らない）
- 1日にお城へ与えられるダメージは最大1,000kcal
- 摂取が基礎代謝の90%未満なら「はらぺこ」扱いでアイテムが出ない
- 目標体重がBMI 17.5未満になる設定はできない

## 動かし方
ビルド不要。`index.html` をブラウザで開くだけ。データは `localStorage` に保存。
設定（右上の歯車）→「デモデータを入れる」で3週間ぶんのサンプルを確認できる。

```
index.html      … アプリ本体
css/style.css
js/app.js
js/mochipoo3d.js … もちプーの3Dモデル本体（ホーム画面とビューアで共通）
js/home3d.js    … ホーム画面の3Dペット
pet3d.html      … もちプーの3Dビューア（Three.js）
js/pet3d.js
```

## もちプー 3D
ホーム画面のペットは3D（Three.js）で表示する。背景は透明で、2Dの空と丘の上にペットだけを重ねている。
表情・体型・着せ替えはアプリの状態と連動し、WebGLやCDNが使えない環境では2DのSVGペットで表示する。

`pet3d.html` をブラウザで開くと、もちプーを3Dでぐるぐる回して見られる。
- 表情（ふつう／うれしい／しょんぼり）・体型（すっきり〜まんまる）・着せ替えアイテム9種を切り替えられる
- タップでジャンプ、まばたき・呼吸・耳のゆれのアニメーション付き
- 「GLBで保存」で .glb ファイルを書き出せる（Blender・Unity・ARビューアなどで使える）
- 顔や耳の位置は、2DのSVG（viewBox 200×200）の座標を3Dの体表に投影して決めているので、2D版と見た目が一致する
